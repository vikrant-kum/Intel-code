# Vikrant Nain — Cloud & DevOps Portfolio

A responsive, single-page static portfolio built with plain HTML, CSS and JavaScript. No build step or framework is required. The supplied portrait is stored locally in `assets/`.

## Preview locally

Open `index.html` in your browser.

## Publish with GitHub Pages

1. Create a GitHub repository (for example, `vikrant-portfolio`).
2. Upload `index.html`, `README.md`, and the `assets/` folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the deployment and open the Pages URL shown in Settings → Pages.

## Personalize before publishing

- Add your preferred email and LinkedIn profile to the contact area if you want direct contact options.
- Replace project cards with live repository/demo links when those are ready.
- Review each skill and project description so it reflects exactly what you want prospective clients to see.
